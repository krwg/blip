Сейчас

Десктоп-клиент для LAN / Hamachi / Radmin VPN: чат, звонки 1:1, файлы, Mesh Pulse. BLIP ID 1–64.

  • P2P на вашей сети UDP + mDNS discovery, TCP между пирами, Mesh Handshake (Ed25519). Никакой регистрации.
  • Чат и звонки Текстовые сообщения, реакции, файлы, 1:1 WebRTC-звонки и демонстрация экрана.
  • Локальный контроль Избранные, блок-лист, статус в LAN, полный UI на EN / RU. Данные остаются у вас.
