# BLIP [2.0.1] — Morse

Patch after **2.0.0 Morse**.

## What's new

### Overlay HUD
- Larger window (**420×420**) — the in-call block is no longer clipped
- Richer Discord/Steam-style panel:
  - Self name + BLIP ID
  - Status / mesh peers / unread stats
  - Activity window title + session time
  - Call: peer id, voice/video, encrypted vs legacy mesh, timer
  - Live transfer progress
  - App version + DND hint

### macOS
- **`BLIP-2.0.1-mac-x64.dmg`** restored (plus arm64 DMG)
- Sequential DMG builds with unique volume titles (fixes CI `hdiutil` races)
