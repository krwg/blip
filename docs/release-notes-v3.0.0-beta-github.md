# BLIP [3.0.0-beta] — Spark

Major line after **2.0.5 Morse**. Version in app: **3.0.0**. Codename: **Spark**.

## Highlights

- **SteamLAN** — optional Steam Networking (App 480) for discovery and peer path when LAN/VPN alone is not enough. Toggle under Settings → Network; advanced lobby controls stay in Developer.
- **NestUI 1.3** — macOS-oriented Liquid Glass: glass on floating chrome only, soft hairline separators, continuous corners, SF Pro type hierarchy, system-blue filled accents.
- **Hardening** — TCP inbound allowlist, DM dedupe, Electron `sandbox: true`, disk-backed file receive, discovery freshness, incremental chat DOM.
- **Identity** — new Apple-style signal mark for app, tray, setup, and portable builds.

## Install / run

| Channel | Artifact |
|---------|----------|
| Windows | `BLIP-Setup-3.0.0.exe`, Portable, `latest.yml` |
